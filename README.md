# StockWise

A self-hosted home inventory tracker for food stock, built with ASP.NET Core Razor Pages, EF Core, and PostgreSQL.

## Features

- Barcode scanning to add and check out stock, with unknown barcodes auto-filled from Open Food Facts
- Bulk add mode for scanning a batch of items in one pass
- Frozen meal batches with individual eat-tracking
- Expiry countdown per item, with configurable notifications
- Full history log of stock and meal events
- Installable as a PWA
